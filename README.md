# ⚡ Rajat Sahu - Developer Portfolio

A sleek, minimalist, dark-mode developer portfolio for **Rajat Sahu** built with **React**, **Vite**, and **Tailwind CSS**, featuring a crimson-accented design, floating dock navigation, interactive contact routing (WhatsApp & Email), and printable PDF resume modal.

---

## 🚀 Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** Font Awesome 6 & Lucide Icons
- **Interactive FX:** Canvas Confetti & Web Audio API clicks

---

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/rajatsahu990-bit/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
